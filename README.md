# SRPG.Battle.Core

개인 개발 중인 **방치형 SRPG**(Unity 2022.3, HD-2D 도트)의 **전투 코어**입니다.
엔진에 붙어 있던 전투 로직을 Unity 의존 없이 떼어내, 콘솔에서 그대로 돌리고 테스트할 수 있게 만든 라이브러리입니다.

```
using 문에 UnityEngine 이 단 한 줄도 없습니다.
외부 의존: System, System.Collections.Generic, System.Text — 그게 전부입니다.
```

## 왜 떼어냈나

전투를 Unity 안에 두면 이 세 가지가 안 됩니다.

1. **테스트가 안 된다.** 재생 버튼을 눌러야만 검증되는 로직은 회귀를 못 잡습니다.
2. **밸런스를 못 돌린다.** 수천 판을 배치만 바꿔가며 자동으로 돌려봐야 수치가 잡힙니다.
3. **리플레이를 못 만든다.** 결과가 float와 프레임 타이밍에 의존하면 같은 판을 두 번 재현할 수 없습니다.

그래서 **모델(전투 규칙)과 뷰(연출)를 먼저 갈랐습니다.** 코어는 결과만 계산하고, 무슨 일이 일어났는지는 `BattleEvent`로 흘려보냅니다. 연출은 그 이벤트를 받아서 그리기만 합니다.

## 설계에서 신경 쓴 것

### 결정론 — 같은 seed면 항상 같은 전투

자동 전투라 리플레이·검증·밸런스 시뮬레이션이 전부 여기에 걸려 있습니다.

- **난수는 `DetRng` 하나만 씁니다.** xorshift128+ 에 SplitMix64 시드 확장.
- **부동소수점을 쓰지 않습니다.** 모든 배율은 천분율 정수(`Permille`, 1000 = 100%)로 계산합니다.
- 룩어헤드가 원본 수열을 소비하면 AI가 실제 전투 결과를 바꿔버리기 때문에, 평가용으로는 `Clone()`으로 갈라 씁니다.

```csharp
// 값 복사가 일어나면 같은 수열을 두 번 소비하는 결정론 버그가 생기므로,
// 의도적으로 참조 타입(class)으로 둔다. (struct 금지)
public sealed class DetRng
```

### 뷰와의 분리

`IEventSink` 구현만 갈아끼우면 같은 전투가 다른 출력으로 나옵니다.

| 구현 | 용도 |
|---|---|
| `NullEventSink` | 밸런스 시뮬레이션 (아무것도 안 그림) |
| `ListEventSink` | 테스트에서 발생 이벤트 검증 |
| `AsciiRenderer` | 콘솔에서 전투판을 눈으로 확인 |

### 기획서 ↔ 코드 추적

주석에 기획 문서의 스펙 ID를 그대로 달아뒀습니다. 수식이 왜 이렇게 생겼는지 코드에서 문서로 바로 넘어갈 수 있습니다.

```csharp
/// <summary>0~999 범위의 천분율 난수를 반환한다. 명중·치명·상태 적용 판정용. (TECH-205)</summary>
public int NextPerMille()
```

## 전투 규칙 요약

- **배치로 이긴다.** 플레이어는 배치만 하고, 전투는 턴제 그리드 위에서 자동 진행됩니다.
- 거리는 전부 **맨해튼**. 대각선은 인접이 아닙니다.
- 이동은 **균일 코스트 BFS**. 벽·적은 통과 불가, **아군은 통과는 되지만 정지 불가**.
- 피격면을 **정면 / 측면 / 후면**으로 나눠 후면 피격(백어택)에 보정이 붙습니다.

## 빌드 & 테스트

```bash
dotnet build src/SRPG.Battle.Core/SRPG.Battle.Core.csproj
dotnet test  tests/SRPG.Battle.Core.Tests/SRPG.Battle.Core.Tests.csproj
```

```
통과!  - 실패: 0, 통과: 39, 건너뜀: 0, 전체: 39
```

테스트는 "돌아간다"가 아니라 **깨지면 게임이 망가지는 것**을 겁니다.

- 같은 seed의 수열 일치, `Clone()` 독립성, 천분율 경계(0‰ / 1000‰)
- 대각선이 인접으로 새지 않는지
- 벽·적·아군의 통과/정지 규칙, 도달 집합의 정렬 순서

## 이 저장소에 없는 것

게임 본체(Unity 프로젝트)는 유료 에셋을 포함하고 있어 공개하지 않습니다.
여기 있는 것은 **전부 직접 작성한 전투 로직**뿐입니다.
